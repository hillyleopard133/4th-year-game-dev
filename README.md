### Packages used
Sprites asset pack I got during my flexible semester.


### How to run
Unzip the build zip and run the "4thYearGameDev" executable file.

### Controls
WASD to move
Space to attack
I and O to place start and end position of A* path visualisation.
P to build the path.
L to rebuild the grid nodes movement penalty array.

### Player objective
Observe the state changes as enemies detect the player.
Kill the enemies
